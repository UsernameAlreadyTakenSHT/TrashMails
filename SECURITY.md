# Security

TrashMails reads email from strangers and talks to third-party servers, so security reports are
welcome.

## Reporting a vulnerability

Please report it privately through GitHub: **Security → Report a vulnerability** on this repository.
Do not open a public issue for it. Include the version, what an attacker controls (an email, a
provider's replies, the device's files…), and steps or an email that reproduces it.

## Supported versions

Only the latest release gets fixes.

## Verifying releases

Release APKs are signed with one key; its certificate fingerprint is in the README
("Verifying a release APK").
