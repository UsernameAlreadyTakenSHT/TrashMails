# TrashMails

Android app to create and read disposable email inboxes from three free providers:

| Provider | Address | Notes |
|---|---|---|
| [Inbox Kitten](https://inboxkitten.com) | `name@inboxkitten.com` (custom or random name) | Public inbox, emails kept ~3 days |
| [Burner Kiwi](https://burner.kiwi) | random, generated by the server | Private (token), inbox and emails expire after 24 h |
| [Maildrop](https://maildrop.cc) | `name@maildrop.cc` (custom or random name) | Public inbox, 10 messages max, emptied after 24 h without mail |

## Features

- Several inboxes side by side, persisted locally
- Auto-refresh every minute while an inbox is open, manual refresh (max once per 30 s)
- HTML emails rendered in a WebView (JavaScript disabled), plain-text fallback
- Copy the address or the message text to the clipboard
- Retention rules of each provider shown when creating or removing an address
- Courtesy creation quota per rolling 24 h: 5 for Burner Kiwi, 20 for the others

No account, no backend, no tracking: the app only talks to the providers' public APIs.

## Build

Requires Android Studio (or a JDK 17+ and the Android SDK, API 37).

```
./gradlew assembleDebug
```

The APK is written to `app/build/outputs/apk/debug/app-debug.apk`. Minimum Android version: 10 (API 29).

## Structure

```
app/src/main/java/com/example/trashmails/
├── data/
│   ├── Models.kt            Provider enum, Inbox, MailSummary, MailProvider interface
│   ├── Http.kt              OkHttp client, name helpers
│   ├── InboxStore.kt        Local persistence of inboxes
│   ├── CreationQuota.kt     Per-provider creation rate limit
│   └── providers/           One implementation per provider
├── ui/
│   ├── MailViewModel.kt     State, navigation, polling
│   └── screens/             Home, inbox and message screens
└── ui/theme/                Material 3 theme
```

## Provider APIs used

- Inbox Kitten: `GET /api/v1/mail/list?recipient=`, `GET /api/v1/mail/getHtml?key=&region=`
- Burner Kiwi: `GET /api/v2/inbox`, `GET /api/v2/inbox/{id}/messages` with `X-Burner-Key`
- Maildrop: GraphQL at `https://api.maildrop.cc/graphql` (`inbox`, `message`, `delete`)

Provider logos are the services' own artwork, rasterized from their SVGs.
